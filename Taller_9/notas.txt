
1. CÁLCULO DE DISTANCIAS EUCLIDIANAS:
Fórmula: d(P, X) = sqrt((x2 - x1)^2 + (y2 - y1)^2)

- Distancia a Cliente 1 (A):
  d(P, A) = sqrt((30 - 20)^2 + (40 - 30)^2)
  d(P, A) = sqrt(10^2 + 10^2) = sqrt(100 + 100) = sqrt(200) ≈ 14.14

- Distancia a Cliente 2 (B):
  d(P, B) = sqrt((30 - 40)^2 + (40 - 50)^2)
  d(P, B) = sqrt((-10)^2 + (-10)^2) = sqrt(100 + 100) = sqrt(200) ≈ 14.14

- Distancia a Cliente 3 (C):
  d(P, C) = sqrt((30 - 35)^2 + (40 - 45)^2)
  d(P, C) = sqrt((-5)^2 + (-5)^2) = sqrt(25 + 25) = sqrt(50) ≈ 7.07

2. CLASIFICACIÓN CON K = 1:
El vecino más cercano (menor distancia) es C(35, 45) con d ≈ 7.07.
Como la clase de C es COMPRA (1), el cliente nuevo se clasifica como: COMPRA.

3. CLASIFICACIÓN CON K = 3 Y ANÁLISIS DE CAMBIO:
Se evalúan los 3 vecinos ordenados por cercanía:
1. Cliente C (d ≈ 7.07) -> COMPRA
2. Cliente A (d ≈ 14.14) -> NO COMPRA
3. Cliente B (d ≈ 14.14) -> COMPRA

Votación democrática: 2 votos COMPRA vs 1 voto NO COMPRA.
Clasificación final con K = 3: COMPRA.
